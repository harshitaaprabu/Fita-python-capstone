# Python Capstone Projects

Two capstone projects from the FITA Academy Python Level 1 syllabus.

| # | Project | Tech | Folder |
|---|---------|------|--------|
| 1 | Web scraping using a Python script | `requests`, `BeautifulSoup`, `csv` | [`01-web-scraper`](01-web-scraper) |
| 2 | Excel automation using Python | `pywin32` (`win32com`) | [`02-excel-automation`](02-excel-automation) |

## Getting started
```bash
git clone https://github.com/<your-username>/fita-python-capstone.git
cd fita-python-capstone
```
Then follow the README inside each project folder.
